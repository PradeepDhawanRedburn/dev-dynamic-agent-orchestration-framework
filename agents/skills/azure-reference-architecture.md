# Azure reference architecture

This skill holds the organisation's own knowledge. The architect cannot write it. It is **not loaded**
while `status` is `needs-content`. See action H-02 in [human-actions.md](../../docs/plan/human-actions.md).

## What the owner must supply

- Landing zone layout: subscriptions, regions approved, network model
- Approved Azure services and the ones not allowed
- Identity, private networking, tagging and naming rules
- Standard patterns already in use, with links to their repositories
