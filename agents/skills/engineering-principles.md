# Engineering principles and standards

This skill holds the organisation's own knowledge. The architect cannot write it. It is **not loaded**
while `status` is `needs-content`. See action H-01 in [human-actions.md](../../docs/plan/human-actions.md).

## What the owner must supply

- The organisation's architecture principles, each with an id and one sentence of rationale
- Mandatory engineering standards: languages, frameworks, API style, testing, logging, security baseline
- Which standards are mandatory and which are guidance
- How an exception is requested and who grants it

## Skill text

```text
SKILL: ENGINEERING PRINCIPLES AND STANDARDS
(To be written by the owner. Short, numbered rules with ids. Under 2,500 characters; longer material goes into organisational memory and is read with a tool.)
```
