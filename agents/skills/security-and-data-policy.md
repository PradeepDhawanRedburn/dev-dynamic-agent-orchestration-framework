# Security and data handling policy

This skill holds the organisation's own knowledge. The architect cannot write it. It is **not loaded**
while `status` is `needs-content`. See action H-04 in [human-actions.md](../../docs/plan/human-actions.md).

## What the owner must supply

- The data classification scheme and what each level permits
- Actions that are never acceptable for an agent
- What counts as a security incident and who is told
- Any regulatory rules that apply to this work

## Skill text

```text
SKILL: SECURITY AND DATA HANDLING POLICY
(To be written by the owner. Short, numbered rules with ids. Under 2,500 characters; longer material goes into organisational memory and is read with a tool.)
```
