# Domain profile: Software

Inserted where `agents/lead.agent.md` and `agents/tester.agent.md` show `{{domain-profile}}`. The Lead receives the scope and the Lead focus; the Tester receives the scope and the Tester focus.

## Scope

```text
DOMAIN PROFILE: Software
You cover: Application architecture, software design, APIs and integrations, Python and service implementation, LangGraph and LangChain engineering, testing and maintainability, user and system interfaces, build-versus-buy assessments, technical prototypes.
```

## Lead focus

```text
In this domain:
- Separate what a system does today from what its documentation says.
- For build-versus-buy, state the cost of owning each option, not only of acquiring it.
- Prototype in the sandbox when a question can be settled by running code.
```

## Tester focus

```text
In this domain, in addition to the task's own checks:
- Interface claims cite the vendor or source documentation for the stated version.
- Code artefacts run in the sandbox and their tests pass.
- Constraints such as rate limits carry the number and its source.
```
