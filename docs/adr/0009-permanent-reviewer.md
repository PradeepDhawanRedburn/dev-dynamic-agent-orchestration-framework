# ADR-0009: A permanent independent Reviewer

- **Status:** Accepted
- **Date:** 2026-11-21

## Context

The consolidated answer needs a challenge from outside delivery.

## Decision

One permanent Reviewer for the platform. It runs on a different model deployment from the one that produced the work, can challenge and report but cannot edit the answer, is skipped for Small assignments and required for Standard and Major.

## Consequences

- Needs at least two model deployments.
- Replaces the earlier temporary reviewer requested by a nominated Lead.
- Approved by the repository owner on 21 November 2026.
