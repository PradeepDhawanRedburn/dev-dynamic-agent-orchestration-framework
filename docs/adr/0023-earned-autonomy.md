# ADR-0023: Earned autonomy

- **Status:** Proposed
- **Date:** 2026-11-21

## Context

Constant approvals cause fatigue, and trust should follow evidence.

## Decision

Proposed: each assignment type starts with all human gates. When measured quality has held above threshold for an agreed number of runs, one low-risk gate for that type may be relaxed. A quality drop or any suspension restores it. Final acceptance of a Major assignment and approval of a change to the estate are never relaxed.

## Consequences

- Needs sign-off from the governance function before it is switched on.
- Not in the first release.
